WordPress 6.9 ベータ3

2025年11月7日 ／ 更新 2026年3月25日 ／ Development、Releases

以下は WordPress.org 公式ブログの記事「WordPress 6.9 Beta 3」の翻訳です。

誤字脱字誤訳などありましたらフォーラムまでお知らせください。

WordPress 6.9ベータ3がリリースされました。ダウンロードして、テストをお願いします。

この WordPress ソフトウェアのベータ版は開発中です。このバージョンの WordPress を本番環境やミッションクリティカルなウェブサイトでインストール、実行、テストしないでください。新機能を試すには、代わりにテスト環境やローカルサイトをセットアップしてください。

WordPress 6.9ベータ3は以下のどの方法でもテストできます。

WordPress Beta Tester プラグインWordPress Beta Tester プラグインをインストールして有効化する。設定では「最前線」チャンネルと「ベータ / RC のみ」ストリームを選択します。
直接ダウンロードBeta 3 version (zip) をダウンロードして、WordPress ウェブサイトにインストールする。
コマンドライン (WP-CLI)WP-CLI コマンドを実行する。wp core update --version=6.9-beta3
WordPress Playground6.9 Beta 3 WordPress Playground instance を使用する。ブラウザで直接ソフトウェアをテストできます。個別のサイトやセットアップは必要ありません。

WordPress 6.9の最終リリース予定日は2025年12月2日です。完全なリリーススケジュールはこちらで確認できます。ベータ版およびRC版のテストへのご協力が、このリリースを可能な限り安定かつ強力なものにするために不可欠です。今後数週間の Make WordPress Core ブログの6.9関連記事をチェックして、追加の詳細情報を確認してください。テストを通じて貢献するみなさんに感謝します !

WordPress 6.9の新機能をキャッチアップ: 6.9の詳細とハイライトについてはベータ1の告知を参照してください。

WordPress 6.9ベータ3をテストする方法

WordPress 6.9のリリースが最高の形で実現するためには、現段階のベータバージョンのテストに協力いただくことが極めて重要です。アップグレードのプロセスをテストいただくことも、また新しく追加された機能を試していただくことも、どちらも等しく重要です。WordPress 6.9の機能テストの手順については、こちらのガイドを参照してください。

問題に遭遇したら、まずサポートフォーラムのアルファ・ベータエリアに報告をしてください。再現可能なバグ報告の作成に慣れている方は WordPress Trac への報告をお願いします。既知のバグの一覧も Trac で閲覧可能です。

リリースのテスト全般について知りたければ、Make Core におけるテスト関連タスクをフォローし、Making WordPress Slack の #core-test チャンネルに参加してください。

WordPress 6.9ベータ3のアップデートとハイライト

WordPress 6.9ベータ3にはベータ2のリリース以来、80件以上のエディターのアップデートと修正が含まれています。

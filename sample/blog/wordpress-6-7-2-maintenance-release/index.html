WordPress 6.7.2メンテナンスリリース

2025年2月12日 ／ Development

以下は WordPress.org 公式ブログの記事「WordPress 6.7.2 Maintenance Release」を訳したものです。

誤字脱字誤訳などありましたらフォーラムまでお知らせください。

WordPress 6.7.2が利用可能です !

このマイナーリリースには35件のバグフィックスが含まれ、ブロックエディター、HTML API、カスタマイザーを含む複数のコンポーネントに影響を与える問題に対処します。

WordPress 6.7.2はショートサイクルリリースです。次のメジャーリリースはバージョン6.8で、2025年4月15日に予定されています。

自動バックグラウンド更新をサポートするサイトでは、更新プロセスが自動的に始まります。

WordPress 6.7.2は WordPress.org からダウンロードできます。または、WordPress ダッシュボードに移動して、「更新」をクリックし、続いて「今すぐ更新」をクリックします。このリリースの詳細については HelpHub にアクセスしてください。

WordPress コントリビューターの皆さんに感謝

本リリースは Aaron Jorbin がリードしました。

WordPress 6.7.2は、以下の方々のコントリビューションなしには実現しませんでした。メンテナンスの修正を安定版リリースとして提供するための地球規模での非同期の連携は、WordPress コミュニティの力と能力の証です。

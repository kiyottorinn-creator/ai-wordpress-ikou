WordPress 7.2 リリース候補版3 (RC3版)

2026年11月25日 ／ 更新 2026年11月25日 ／ Announcement、Development、7-2

以下は WordPress.org 公式ブログの記事「WordPress 7.2 Release Candidate 3」の翻訳です。

誤字脱字誤訳などありましたらフォーラムまでお知らせください。

WordPress 7.2リリース候補版 3 (RC3) のテストの準備が整いました !

このバージョンの WordPress ソフトウェアは現在もまだ、開発中です。 このバージョンの WordPress を本番サイトや重要なウェブサイトにインストール、実行、テストしないでください。 新機能を試すには、代わりにテスト環境やローカルサイトをセットアップしてください。

あれ、7.2 RC2 はどうなったのでしょうか ? WordPress 7.1.5 の変更内容が、同じタイミングで WordPress 7.2 RC2 として反映されています。

WordPress 7.2リリース候補版3 をテストする方法

WordPress 7.2 RC3 は以下のいずれかの方法でテストできます。

プラグインWordPress Beta Tester プラグインをインストールして有効化する。設定で「最前線」チャンネルと「ベータ / RC のみ」ストリームを選択します。
直接ダウンロードRC3 version (zip) をダウンロードして、WordPress サイトにインストールする。
コマンドラインWP-CLI コマンドを実行する。 wp core update --version=7.2-RC3
WordPress PlaygroundWordPress Playground instance を使用する。ブラウザーで直接ソフトウェアをテストできます。個別のサイトやセットアップは必要ありません。

WordPress 7.2 の最終リリース日は2026年12月8日を予定しています。リリーススケジュールの詳細はこちらをご覧ください。ベータ版とリリース候補版のテストにご協力いただくことは、最終リリースを安定した、パワフルなものにするために必要不可欠です。テストにご協力くださる皆様に感謝いたします !

今後数週間、引き続き Make WordPress Core ブログで 7.2 関連の情報はご確認ください。

RC1 以降のコアの変更点

WordPress 7.2 の詳細については、RC1 のお知らせをご覧ください。 RC1 以降に対応したすべての問題の技術的な詳細は、以下のリンクから確認できます。

  • 2026年11月17日以降の 7.2 対象のクローズされた Trac チケット一覧
  • 2026年11月17日以降の 7.2 対象の Gutenberg コミット

今回のリリースでは、さらなるバグ修正、アクセシビリティの改善、互換性に関する更新が行われています。具体的には、クライアント側でのメディア処理の改善、項目数が最新の状態に更新されていないナビゲーションメニューの修正、HTML やリビジョンのメタデータの処理の信頼性向上などです。さらに、メールヘッダー処理の強化、フォントのアップロードに関する互換性の問題への対応、大規模サイトでのランダムなコンテンツへのリダイレクト処理のパフォーマンス改善も行われています。

詳細はこちら: Trac #66769, Trac #66668, Trac #66102, Trac #66490, Trac #66654

ブロックエディターのさらなる改善

WordPress 7.2 RC3 では、ブロックエディターのさらなる調整が行われ、セキュリティ、アクセシビリティ、メディア処理が改善されています。最近の修正には、外部画像のメタデータやエンティティレコードの処理の強化、メディア変換時のファイル名の保持、Interactivity API のクライアント側とサーバー側の動作の一貫性向上が含まれます。さらに、階層構造を持たない投稿タイプのエディターコントロールの簡素化や、アクセシビリティラベルの改善も行われています。

詳細はこちら: GitHub #87015, GitHub #87150, GitHub #87275

コントリビュートの方法

WordPress は、情熱を持って開発に携わるコミュニティの協力と貢献によって成り立っているオープンソースソフトウェアです。以下では、技術的な専門知識の有無を問わず、世界で最も人気のあるオープンソースの Web プラットフォームを支援するさまざまな方法をご紹介します。

テストに参加する

問題のテストは、あらゆるソフトウェア開発において不可欠です。また、誰もが貢献できる有意な方法です。 WordPress 7.2 リリース候補版3 のテストにご協力いただくことは、最終リリースを最高の状態に仕上げるための重要な鍵となります。アップグレード手順のテストが不可欠である一方で、新機能を試していただくことも同じくらい重要です。この詳細ガイドでは、WordPress 7.2 の各新機能をテストする手順を順を追ってご紹介します。

リリースのテスト全般について知りたければ、Make Core におけるテスト関連タスクをフォローし、Making WordPress Slack の #core-test チャンネルに参加してください。

テーマやプラグインを更新する

プラグインやテーマの作者のみなさん、WordPress の機能を拡張しすべてのユーザーにその価値を広める上であなたの作品が果たす役割は重大です。 RC3 の公開に合わせて、テストを終了し、プラグインの readme ファイル「Tested up to」バージョン指定を 7.2 に更新してください。

互換性の問題を見つけた場合は詳しい情報をサポートフォーラムに投稿してください。

ホスティングプラットフォームでテストする

WordPress のテストを支援してくださっているすべての Web ホスティング事業者の皆さんに感謝します。 Web ホスティング事業者は、WordPress とそのユーザーを支える重要なインフラを提供しています。ホスティング環境でのテストは、開発プロセスに有益な情報をもたらすとともに、WordPress とホスティングプラットフォームの完全な互換性、エラーのない動作、最適なユーザー体験を実現するための最適化、そしてアップデートがユーザーのサイトに問題なく反映されることを確認するうえで役立ちます。
